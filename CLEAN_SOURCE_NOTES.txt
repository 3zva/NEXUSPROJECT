NEXUS_REQUIRED_SOURCE clean source package

This folder contains only the files needed to build the current native host applications.

Final build output:
%USERPROFILE%\Desktop\NEXUS

Expected output structure:
- Nexus Loader.exe
- configs\
- nexus-ui\
- nexus-client\
- nexus-runtime-core\
- runtime\

Intentionally excluded:
- Old Python/PyInstaller source and executables.
- Generated Qt/CMake build folders.
- Config backup history.
- ZIP archives.
- Logs.
- Validation/helper scripts not used by the host apps.
- Unused WebView2 package contents and non-x64 runtimes.

Run build.bat from this folder to rebuild the Desktop NEXUS output.

Single-file release:
Run deployment\BUILD-SINGLE-EXE.ps1 after build.bat to create one public EXE
that contains the full Desktop NEXUS runtime and launches it after extraction.
Pass -GitHubOwner 3zva -GitHubRepo NEXUSPROJECT for public releases. The
script remembers them in
deployment\release-settings.json, updates cloudflare-worker\wrangler.jsonc
with the new version, GitHub download URL, SHA-256, and size, then refreshes
the Desktop NEXUS-GitHub-Release folder.
Add -CommitReleaseMetadata to commit the Worker release metadata after the
standalone EXE is packaged. Add -CreateGitHubRelease to create/update the
GitHub Release and upload the EXE; this requires GitHub CLI and gh auth login.
Redeploy the Cloudflare Worker after every public release so the signed
latest-release manifest and /download redirect use the new version, SHA-256,
size, and URL.

GitHub Releases URL:
https://github.com/3zva/NEXUSPROJECT/releases
