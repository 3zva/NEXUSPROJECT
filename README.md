## Overview

NEXUS is a desktop configuration hub built for Rainbow Six Siege players who want one place to manage operator settings, loadouts, sensitivity values, save files, and client preferences.

The goal is simple: keep your setup organized, consistent, and easy to update without digging through separate files or rebuilding settings every time.

> **Official downloads, licenses, updates, and support are available only through [highcloudnexus.com](https://highcloudnexus.com).**

---

## Features

### Operator Configuration

- Manage settings for every supported attacker and defender
- Select operator weapons and attachments
- Store separate primary and secondary weapon values
- Adjust horizontal and vertical values independently
- Configure independent recoil ramp values
- Set rapid-fire behavior for Weapon 1, Weapon 2, or both

### Sensitivity and FOV

- Normalize sensitivity values
- Configure aspect ratio and vertical FOV
- Manage supported optic values
- Keep settings consistent across different setups

### Save File Management

- Import one complete NEXUS configuration
- Export one complete backup
- Restore the full operator catalog at once
- Move configurations between supported devices

### Client Tools

- Configure keybinds
- Adjust appearance and interface preferences
- Manage supported performance and startup options
- Select a screen region for supported monitoring and overlay features

## Configuration System

NEXUS uses one global configuration file for the complete operator catalog.

This means:

- Operator data is stored together
- Importing a configuration updates the complete catalog
- Exporting creates one complete backup
- Individual operators do not use separate import or export files

This makes it easier to keep backups, move a setup between devices, and restore everything from one file.
