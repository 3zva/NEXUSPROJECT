# Security Policy

## Official Distribution

Official NEXUS downloads are distributed through:

https://highcloudnexus.com

Do not download or install NEXUS from unofficial mirrors, reuploads,
modified builds, or third-party license sellers.

## Reporting a Security Issue

Please report suspected security vulnerabilities, unauthorized
redistribution, license bypasses, impersonation, or malicious copies
privately through:

https://highcloudnexus.com/contact/

Please include:

- A clear description of the issue
- The affected version
- Steps to reproduce, when applicable
- Screenshots, logs, or supporting evidence
- A safe method for follow-up contact

Do not publicly disclose an unresolved vulnerability before there has
been a reasonable opportunity to investigate it.

## Supported Versions

Security and update support applies to the latest official NEXUS
release unless otherwise stated on the official website.
